# Arcanean Library — Agent Contract

## Repository identity

`frankxai/arcanean-library` owns fictional Arcanean codices, rituals, poems,
teaching stories, and in-world learning experiences. Treat every work here as
narrative IP from the Arcanea universe unless a file explicitly says otherwise.

## Fiction boundary

- Do not store historical sacred texts, real-world religious corpora, documentary evidence, critical editions, or modern scholarship in this repository.
- Words such as `sacred`, `vision`, `scripture`, `wisdom`, and `library` do not establish repository fit. Classify the artifact before writing.
- External traditions may inform clearly labeled source notes, but their primary texts and rights records remain in the nonfiction research authority.
- Never present new Arcanea writing as the words of a historical thinker or as an ancient recovered source.
- Keep fiction, quotation, translation, interpretation, and research provenance visibly separate.

## Current nonfiction authority

Historical sacred-source witnesses used by FrankX contemplative work live at
`frankxai/frankx.ai-vercel-website/research/sacred-texts`. `Sacred Visions` is
currently an editorial collection within that research layer, not an Arcanea
collection and not a standalone repository.

The planned `reality-intelligence-system` is a future portable framework
extraction. It is not an existing repository and does not currently own the
historical corpus.

## Pre-write gate

Before adding content:

1. Read this file, `README.md`, `LICENSE`, and `LICENSING.md`.
2. State whether the artifact is fiction, historical source, translation, interpretation, or product code.
3. Stop if the answer is not `fiction` or Arcanean product code; resolve the canonical repository first.
4. Use a branch and pull request for every mutation.
