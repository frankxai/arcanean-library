# The Gentle Powers

Classification: original Arcanean fiction and visual-production proposals.
Canon state: proposal. Publication intent: public review collection.
Owner request: Frank Riemer, 30 October 2026.
Implementation issue: https://github.com/frankxai/arcanea-ai-app/issues/699

This collection explores power through protection, reciprocity, hospitality and
cooperation. It contains twelve prompt directions and three generated frames,
including a deliberate second camera angle of the same protector. Nine directions
have not been generated. No game, animation or Unreal asset is claimed.

`collection.json` owns narrative choices, prompt text, camera intent, costs,
game-mechanic proposals, generated-image checksums and review observations.
`PROMPTS.md` is the readable prompt projection. The application consumes a
commit-pinned projection; it does not become a second fiction authority.

Ilyra is a working character name, not a new member of the Ten Guardians. Her
name is a coined sound choice, without asserted historical etymology or completed
trademark clearance. The first image prompt used “guardian” descriptively. No
new origin class, Gate, Godbeast bond or locked truth is introduced.

Research links are labeled interpretive notes. This collection contains no
historical sacred texts, translated religious corpus or copied game artwork.
The user supplied a photograph of the cover of *Angels in Art*. The book's
contents, edition and authorship were not verified. We draw from the visible
qualities of tenderness, gesture and atmosphere, without reproducing the cover.
